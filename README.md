# نظام كاشير (POS) لصالون تجميل — Salon POS

تطبيق Flutter كامل، يعمل بدون إنترنت (Offline)، بقاعدة بيانات SQLite محلية،
يُصدر لنسخة كمبيوتر (Windows) ونسخة هاتف (APK) من نفس الكود.

## المميزات المنفذة
- ✅ إدارة الخدمات والأسعار (إضافة/تعديل/حذف)
- ✅ إدارة بيانات العملاء
- ✅ تسجيل وإدارة المواعيد (حالة: قيد الانتظار/مؤكد/تم/ملغي)
- ✅ نظام فواتير كامل (خدمات + منتجات، خصم، طريقة دفع)
- ✅ متابعة المخزون مع تنبيه انخفاض الكمية، وخصم تلقائي من المخزون عند البيع
- ✅ تقارير مبيعات (يومي/أسبوعي/شهري/إجمالي)
- ✅ الوضع الليلي/النهاري (Dark/Light Mode)
- ✅ هوية بصرية بيبي بلو + أسود
- ✅ دعم كامل للعربية واتجاه RTL
- ✅ يعمل بالكامل Offline (لا يحتاج إنترنت إطلاقاً)

## 🚀 أسرع طريقة تحصل بيها على ملف APK جاهز (بدون تثبيت أي برنامج على جهازك)

المشروع فيه ملف جاهز (`.github/workflows/build_apk.yml`) يخلي GitHub يبني الـ APK ليك مجاناً. اتبع الخطوات دي بالترتيب:

1. **اعمل حساب على GitHub** (لو معندكش) من [github.com](https://github.com) — مجاني.
2. اعمل **مستودع جديد (New repository)** — سمّيه مثلاً `salon-pos` — واختاره **Private** لو عايز الكود يفضل خاص.
3. ارفع كل ملفات المشروع (اللي جوه الملف المضغوط ده) على المستودع:
   - أسهل طريقة: من صفحة المستودع اضغط **Add file → Upload files**، واسحب كل محتويات مجلد `salon_pos` (بما فيها مجلد `.github` المخفي).
   - أو لو عندك خبرة بـ Git:
     ```bash
     cd salon_pos
     git init
     git add .
     git commit -m "أول نسخة"
     git branch -M main
     git remote add origin https://github.com/USERNAME/salon-pos.git
     git push -u origin main
     ```
4. روح لتبويب **Actions** في المستودع — هتلاقي عملية اسمها **Build APK** شغالة تلقائياً (بتاخد حوالي 3-5 دقائق).
5. لما تخلص (علامة ✅ خضراء)، افتحها واضغط عليها، وهتلاقي تحت في قسم **Artifacts** ملف اسمه **salon-pos-apk** — حمّله، فكه (zip)، جواه هتلاقي `app-release.apk`.
6. انقل الملف ده لموبايلك (عبر واتساب لنفسك، جوجل درايف، أو كابل USB) وثبته.

> ملاحظة: أول مرة تنصب تطبيق خارج جوجل بلاي، الموبايل هيسألك تفعيل "تثبيت من مصادر غير معروفة" — دي خطوة عادية وآمنة طالما الملف من مصدرك أنت.

**بعد التثبيت، التطبيق هيشتغل بالكامل Offline** — مفيش أي استدعاء إنترنت في كود التطبيق نفسه، الإنترنت كان مطلوب بس في خطوة البناء دي لمرة واحدة.

## طريقة بديلة: البناء من جهازك مباشرة (لو عندك كمبيوتر وتفضل التحكم الكامل)

## متطلبات التشغيل
1. ثبّت [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار 3.x أو أحدث)
2. تأكد من `flutter doctor` أن كل شيء تمام

## خطوات التشغيل
```bash
cd salon_pos
flutter pub get
flutter run          # للتجربة السريعة على أي جهاز متصل
```

## تصدير نسخة الكمبيوتر (Windows)
```bash
flutter config --enable-windows-desktop
flutter build windows --release
```
الملف الناتج (.exe) هيكون في:
`build/windows/x64/runner/Release/`

> ملاحظة: بناء نسخة Windows لازم يتم فعلياً على جهاز Windows (أو عبر GitHub Actions).

## تصدير نسخة الهاتف (APK)
```bash
flutter build apk --release
```
الملف الناتج هيكون في:
`build/app/outputs/flutter-apk/app-release.apk`

للحصول على حجم أصغر (مقسم حسب معمارية المعالج):
```bash
flutter build apk --split-per-abi
```

## نقاط تحتاج قرارك لاحقاً (اختياري للتطوير)
- **الطباعة**: مكتبة `printing` و `pdf` مُضافة بالفعل بالمشروع؛ لسه محتاجة شاشة تصميم فاتورة PDF فعلية لو عايز تطبع الفواتير على طابعة حرارية أو عادية.
- **نسخ احتياطي / استيراد بيانات**: ملف قاعدة البيانات هيتخزن في مجلد بيانات التطبيق، ممكن نضيف زر "نسخ احتياطي" يصدّر الملف لمكان يختاره المستخدم.
- **صلاحيات مستخدمين متعددين (كاشير/أدمن)**: مش موجودة حالياً، ممكن تُضاف لو الصالون فيه أكتر من موظف كاشير.
- **الشعار**: أيقونة التطبيق حالياً افتراضية، لو عندك لوجو للصالون ابعته وهضيفه كـ App Icon.
